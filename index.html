        Hardware

        Lodestar T4. Built for the vehicle, not the dashboard.

        A sealed unit that installs behind the dash or on the chassis in under 40 minutes. It reads vehicle data from the CAN bus and keeps recording when the network drops out.

        Each unit ships pre-provisioned with an eSIM that roams across EU networks. Installation is done by certified partners, or by your own workshop with our fitting guide.

        GNSS performance

        More satellites overhead, a tighter fix on the ground.

        The T4 tracks four constellations on two frequency bands. The L5 signal resists the reflections that make single-band receivers drift between tall buildings.

        Sky plot · LS-204 receiver

        Centre is the zenith. Rings mark 30° and 60° elevation. Hollow markers are tracked but not used in the solution.

        Signal strength, dB-Hz

        Carrier-to-noise density per satellite. Signals under 28 dB-Hz or below 10° elevation are excluded from the fix.

        Developers and integrations

        Raw NMEA or clean JSON. Same fix, your systems.

        Point an existing dispatch system at the NMEA 0183 feed, or call the REST API and receive JSON with geofence membership already resolved. The stream follows the vehicle selected in the console.

        • GET /v1/units/{id}/track history by time range
        • POST /v1/geofences create a zone

        Security and privacy
        
        
          
        Location data is personal data. We treat it that way.
        
          
        Lodestar is built to pass works-council review. What is collected, who can see it and how long it is kept are set per account and recorded in the audit log.
