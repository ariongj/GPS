# Lodestar GPS

Demo website for a fictional fleet-tracking company, in a clean, minimal, Apple-style look. It's a single self-contained `index.html` with no build step: open it in a browser.

## Sections

- **Hero:** "Every vehicle. Every second." The live map runs inside a studio-display mockup.
  - Six simulated vehicles drive around Prishtina on an Apple Maps-style map.
  - A frosted-glass fleet list with All / Moving / Stopped filters.
  - A card that follows the selected vehicle.
- **Accuracy:** three large figures (1.5 m, 1 sec, 72 h).
- **Features:** a bento grid covering route replay, alerts, geofences, driver scores, idle time and integrations.
- **Tracker:** the Lodestar T4 device on a black band, with key specs.
- **Phone app:** a phone mockup whose list shows the same live vehicles as the map.
- **How it works:** three steps.
- **Rest of the site:** simple pricing, a demo request form (it sends nothing) and the footer.

All vehicles and data are simulated.
