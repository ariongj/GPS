# Lodestar GPS

Demo website for a fictional fleet-tracking company, in a clean, minimal, Apple-style look. It's a single self-contained `index.html` with no build step: open it in a browser.

**Live site:** https://ariongj.github.io/GPS/ (deployed from `main` by GitHub Actions).

## Languages

English and Albanian (Shqip). Use the EN / SQ switch in the navigation. The choice is remembered, and Albanian is picked automatically for browsers set to Albanian. Live parts of the page are translated too: vehicle names and statuses, notifications, chart labels, integration samples and coordinates (V / L).

## Sections

- **GPS layer and page route:** across the whole page, faint globes turn while satellites orbit and location pings pulse with city coordinates. The layer drifts as you scroll and keeps clear of the text column. On wide screens, a route on the right edge shows your position on the page as a moving vehicle, with a waypoint for each section that you can click to jump there.

- **Hero:** "Every vehicle. Every second." The live map runs inside a studio-display mockup.
  - Six simulated vehicles drive around Prishtina on an Apple Maps-style map.
  - Select a vehicle and the camera zooms in to follow it. "Show all vehicles" zooms back out.
  - A frosted-glass fleet list with All / Moving / Stopped filters, and a card for the selected vehicle.
- **Accuracy:** three large figures that count up as they come into view.
- **Features:** an interactive bento grid.
  - Route replay with play and scrub controls.
  - Live alerts generated by the simulated fleet.
  - An animated geofence with an adjustable zone size.
  - Driver score rings with a driver switcher.
  - An idle-time chart with a Week 1 / Week 4 toggle.
  - Integration samples: REST, webhooks, CSV, MQTT, NMEA and email reports.
- **Tracker:** the Lodestar T4 on a black band, with tappable hotspots and key specs.
- **Phone app:** a phone mockup whose list shows the same live vehicles as the map. Tapping a vehicle there follows it on the map.
- **Rest of the site:**
  - How it works, in three steps.
  - Pricing with a fleet-size calculator.
  - FAQ.
  - A demo request form (it sends nothing).

All vehicles and data are simulated.

## Deploying

Every push to `main` runs `.github/workflows/pages.yml`. The workflow copies the site to the `gh-pages` branch, and GitHub Pages serves it from there at https://ariongj.github.io/GPS/.
